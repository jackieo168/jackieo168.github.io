Here are some of the projects I've worked on. Most of them are related to data science and were completed during my Master's program, MIDS at UC Berkeley.

GenAI Project

RAG System For Marketing Vs. Research QA

Built and optimized a RAG + LLM pipeline to generate quality responses for 2 different user personas: marketers vs. researchers.

Class: DATASCI 267 (Generative AI, MIDS)

Computer Vision Project

Brain Tumor Classification

Built and optimized different computer vision features (e.g. Canny Edges, DoH, DoG), ViT-based features, and classification models to classify 4 types of brain tumor classes from MRI images with 96.7% test accuracy.

Class: DATASCI 281 (Computer Vision, MIDS)

: report, presentation, GitHub

ML at Scale Project

Predicting Flight Delays

Built and optimized a distributed ML pipeline using PySpark to analyze a timeseries dataset of 30M+ flights (along with secondary datasets) and predict flight delays at least 2 hours in advance.

Class: DATASCI 261 (ML at Scale, MIDS)

: report

ML Classification Project

Built and optimized an ML pipeline to analyze Expedia hotel search data and predict the corresponding hotel cluster (100 classes).

Class: DATASCI 207 (Applied ML, MIDS)

: presentation, Google Colab notebook
